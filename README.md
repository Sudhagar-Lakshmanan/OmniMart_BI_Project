# OmniMart_BI_Project

# 📊 Revenue Dashboard Project

## 🧠 Business Context

This project was initiated to address key challenges in revenue tracking, product performance, and customer engagement. The Business Requirements Document (BRD) outlines the full scope, including:

- ✅ Business Goals & Success Criteria
- 🔍 Current vs Future State Process Flows
- 📈 KPIs and Metrics for Dashboard Pages
- 🧩 Role-Based Access Matrix
- 🧪 Use Cases, Epics, and User Stories
- 🗂️ Wireframes and Visual References
- 📌 Risk, Assumptions, and Dependencies


For traceability, all queries, visuals, and UAT artifacts are mapped to sections in the BRD and its appendices.
