# Process Flows Overview

This folder contains visual representations of the data movement and workflow transformation for the Omnichannel Retail Dashboard project. All diagrams were created using **"Lucidchart"**.



## 1. Current-State Process Flow

**File:** [Current State "As-Is"](1_Process_flow_Current_state.png)

This diagram outlines the fragmented manual reporting processes currently followed by Sales, Marketing and Support teams. It highlights system disconnects, lack of automation and absence of consolidated dashboards.



## 2. Future-State Process Flow

**File:** [Future State "To-Be"](2_Process_flow_Future_state.png)

This diagram illustrates the optimized, centralized reporting process using the Power BI solution. It shows automated data flows, stakeholder-specific access and integrated insights across departments.
