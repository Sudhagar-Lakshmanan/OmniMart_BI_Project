# 📊 Omnichannel Retail Behaviour and Performance Analytics Dashboard

This repository showcases a comprehensive analytics solution for a fictional retail company, **OmniMart Pvt Ltd**, designed to analyze customer behavior, campaign performance, and operational KPIs across multiple channels.

It includes business documentation, process flows, wireframes, SQL logic, Power BI dashboards, data dictionary, UAT artifacts, and executive summaries — all structured for clarity, traceability, and stakeholder usability.

---

## 🏢 Branding & Stakeholder Disclaimer

- All company names, stakeholder personas, and branding elements in this repository are **fictional** and used solely for illustrative purposes.
- The logo and visual assets are **AI-generated** to simulate a realistic enterprise environment.
- No real individuals, organizations, or proprietary data are represented.

---

## 📁 Folder Structure

### `01_Business_Documents/`
Business request email, BRD, extracted business questions, user stories, and use cases.

### `02_Process_Flow_Diagrams/`
Current and future state process flows visualizing operational transitions.

### `03_Wireframes/`
Dashboard wireframes for each page, aligned with user stories and BRD expectations.

### `04_SQL_Queries/`
Modular SQL scripts for setup, analysis, and output. Includes ERD and Markdown summaries.

- `i_Setup_Scripts/`: Table creation, data cleaning, and ERD
- `ii_Analysis_Queries/`: Revenue, products, customers, campaigns, support tickets
- `iii_Output/`: Markdown summaries and Excel outputs

### `05_PowerBI_Dashboard/`
Power BI assets including `.pbix` file, PDF report, animated GIFs, and data model diagram.

### `06_Data_Dictionary/`
Column-level definitions and table relationships for transparency and developer onboarding.

### `07_User_Acceptance_Testing/`
UAT execution report with test cases, results, and stakeholder sign-off.

### `08_Executive_Summary/`
Final presentation summarizing business impact, insights, and dashboard walkthrough.
