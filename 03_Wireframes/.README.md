# Wireframes Overview

## Purpose

This folder contains low-fidelity wireframes created using **"Balsamiq"** to visualize the proposed layout, navigation, and interactivity of the Power BI dashboard. These wireframes serve as a visual reference to align stakeholder expectations with the dashboard’s design and functionality prior to development.

---

## Contents

| File Name                        | Description                                                                 |
|----------------------------------|-----------------------------------------------------------------------------|
| `Summary`                        | Overview of the analysis                                                    |
| `Overview_Page_Wireframe.pdf`    | Layout of the Overview page with dynamic card visuals and navigation button |
| `Revenue_Page_Wireframe.pdf`     | Wireframe showing revenue KPIs and filters                                  |
| `Product_Page_Wireframe.pdf`     | Product performance layout and slicer placement                             |
| `Customer_Page_Wireframe.pdf`    | Customer segmentation and metrics layout                                    |
| `Campaign_Page_Wireframe.pdf`    | Campaign effectiveness and engagement visuals                               |
| `Support_Page_Wireframe.pdf`     | Support ticket trends and resolution metrics                                |



## 🧩 Key Design Notes

- **Low-Fidelity Format**: Wireframes are intentionally minimal to focus on layout and user flow.
- **Dynamic Content**: Overview page includes card visuals powered by DAX for real-time summary metrics.
- **Navigation**: Page navigation buttons are included to simulate user flow across dashboard sections.
- **Stakeholder Alignment**: Wireframes reflect BRD content and are referenced in **Appendix B.1 of the BRD.**
