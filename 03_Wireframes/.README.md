# Wireframes Overview

## Purpose

This folder contains low-fidelity wireframes created using **"Balsamiq"** to visualize the proposed layout, navigation, and interactivity of the Power BI dashboard. These wireframes serve as a visual reference to align stakeholder expectations with the dashboard’s design and functionality prior to development.

| [Summary Page](1_Summary_page.png)     | High-level summary contains key findings        |

## Key Design Notes

- **Low-Fidelity Format**: Wireframes are intentionally minimal to focus on layout and user flow.
- **Dynamic Content**: All pages includes card visuals powered by DAX for real-time summary metrics.
- **Navigation**: Page navigation buttons are included to simulate user flow across dashboard sections.
- **Stakeholder Alignment**: Wireframes reflect BRD content and are referenced in **Appendix B.1 of the BRD.**
