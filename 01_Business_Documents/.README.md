# Business Documents Overview

This folder contains the foundational documents that define the scope, objectives, and requirements of the "Omnichannel Retail Behaviour and Performance Analytics Dashboard" project.




## Business Request Email

**File:** [Business Request Email](01_Business_Documents/1_Sample_Business_Request_Email.docx)
Outlines the initial request from stakeholders, including business goals, expected deliverables, and timeline expectations.




## Business Requirements Document (BRD)

**File:** [BRD](01_Business_Documents/2_Business_Requirements_Document_(BRD).docx)

**A comprehensive document detailing:**

- Project scope and success criteria  
- Current vs future state process flows  
- KPIs and dashboard metrics  
- Functional and non-functional requirements  
- Role-based access matrix  
- Wireframes and visual references  
- Epics, user stories, and stakeholder mapping  
- Use case overview and actor matrix  
- Risks, assumptions, and dependencies  
- Approval and sign-off section

**Appendices include:**
- Business case questions and insights  
- Dashboard wireframes  
- Process flow diagrams  
- Epic and user story tables  
- Use case mapping
